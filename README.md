# General Physics Interactive Demos

Simple interactive HTML demos for General Physics II.

## GitHub Pages
1. Create a GitHub repository, e.g. `general-physics-demos`.
2. Upload all files and folders in this directory to the repository root.
3. In GitHub: Settings → Pages.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Open the GitHub Pages URL shown by GitHub after deployment.

The demo URLs will look like:
- `/electrostatics/point-charge.html`
- `/electrostatics/uniform-field.html`
